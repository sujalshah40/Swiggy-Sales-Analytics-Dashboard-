# 🍔 Swiggy Sales Analytics Dashboard | Excel

## 📊 Project Overview

An interactive **Swiggy Sales Analytics Dashboard built using Microsoft Excel** to analyze sales performance, customer ratings, orders, restaurants, food types, cities, states, and sales trends.

## 📌 Key KPIs

- 💰 Total Sales: ₹53.01M
- ⭐ Average Rating: 4.34
- 💬 Rating Count: 5.59M
- 📦 Total Orders: 197.43K
- 🧾 AOV: ₹268.51

## 📈 Dashboard Features

- Monthly Sales Trend
- Sales by Food Type (Veg vs Non-Veg)
- State-wise Sales Analysis
- Top 5 Restaurants by Sales
- Top 5 Cities by Sales
- Weekly Sales Trend
- Interactive Month and City Filters

## 🛠️ Tools & Skills

- Microsoft Excel
- Pivot Tables & Pivot Charts
- Slicers
- Data Cleaning & Analysis
- Data Visualization
- Dashboard Design
